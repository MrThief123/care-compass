# User Stories — ADM-09 Admin — Edit, extend or cancel a shift

Format: As a [user], I want [capability], so that [outcome].

## US-01
As an admin, I want the database to refuse changes to a shift's client or to a deactivated carer, so that the roster stays valid (editing and extending were dropped, CHG-053: cancel and assign again).

- Acceptance criteria: AC-01, AC-02, AC-05
- Requirements: REQ-24

## US-02
As an admin, I want to cancel a shift that is no longer needed, so that the roster is right and the history is kept.

- Acceptance criteria: AC-03, AC-06, AC-07, AC-09
- Requirements: REQ-24

## US-03
As an admin, I want shifts that have already ended to stay as they were, so that the care record cannot be rewritten by accident.

- Acceptance criteria: AC-04, AC-08
- Requirements: REQ-24
