# User Stories — ADM-05 Admin — Remove client

Format: As a [user], I want [capability], so that [outcome].

## US-01
As an admin, I want to remove a client my organisation no longer serves, so that my staff lose access but the family keeps everything.

- Acceptance criteria: AC-01 to AC-06, AC-10
- Requirements: REQ-04, REQ-N6

## US-02
As a family member, I want to be told, on Settings and Home, that my organisation has removed the client and I need to choose a new one, so that I am not left without care cover and without knowing why.

- Acceptance criteria: AC-07 to AC-09
- Requirements: REQ-04
