# User Stories — ADM-11 Admin — Client view

Format: As a [user], I want [capability], so that [outcome].

## US-01
As an organisation admin, I want to open one of my clients and see what their family sees, so that I understand their care and budget.

- Acceptance criteria: AC-01, AC-02
- Requirements: REQ-38

## US-02
As an organisation admin, I want to do anything the family can for my client, so that care and money keep being managed when the family is no longer there.

- Acceptance criteria: AC-03, AC-04
- Requirements: REQ-38, REQ-07, REQ-29

## US-03
As a family, I want admins of other organisations kept out of my client's records, so that our information stays private.

- Acceptance criteria: AC-05
- Requirements: REQ-38
