# User Stories — ADM-08 Admin — Manage carer-client assignments

Format: As a [user], I want [capability], so that [outcome].

## US-01
As an admin, I want to remove a carer from a client, so that they no longer access that client.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-06
- Requirements: REQ-05, REQ-06

## US-02
As an admin, I want to see which clients each carer is assigned to, so that I know who I am removing and from whom.

- Acceptance criteria: AC-04, AC-05, AC-07
- Requirements: REQ-06
