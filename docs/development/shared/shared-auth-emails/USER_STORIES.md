# User Stories — F0-24 Auth emails: working reset and invite links, set-password page

## US-01
As someone who forgot my password, I want the emailed link to let me choose a new one and sign in, so that I am not locked out.

- Acceptance criteria: AC-01, AC-02, AC-06
- Requirements: REQ-01

## US-02
As a carer invited by my organisation, I want the invite email to take me to a page where I set my password and arrive on my home screen, so that I can start work.

- Acceptance criteria: AC-03, AC-04
- Requirements: REQ-01, REQ-06

## US-03
As an organisation admin, I want to resend an invite to a carer who has not signed in, so that a lost or expired email does not block onboarding.

- Acceptance criteria: AC-05
- Requirements: REQ-06

## US-04
As the project owner, I want the email settings recorded and in the repository, so that the hosted project can be set up and checked.

- Acceptance criteria: AC-07
- Requirements: REQ-01
