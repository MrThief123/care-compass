# User Stories — UI-04 Screen data contracts and fixtures: full-history Task log, single occurrence, event documents

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a family member, I want to page, search and filter the whole task history, open any task and see its documents, so that I can find any care record however old.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-04, AC-05, AC-06
- Requirements: REQ-19

## US-02
As a screen developer, I want contract functions that behave like the real history and fixtures that match the designs and exercise long data, so that I can build and verify screens now and wire real data later without rewriting them.

- Acceptance criteria: AC-07, AC-08, AC-09, AC-10
- Requirements: REQ-N9
