# User Stories — INT-12 Cross-role integration journey

Format: As a [user], I want [capability], so that [outcome].

## US-01
As the team, I want one command that runs every main journey against a real database and cleans up after itself, so that we can check the whole product before every release.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-42, AC-43, AC-44

## US-02
As a Family member, carer or admin, I want to create my account, sign in (with a code for admins) and reset my password, so that I can always get into my own dashboard and only my own.

- Acceptance criteria: AC-04 to AC-11
- Requirements: REQ-N4, REQ-N5

## US-03
As a Family member, I want to view, create, open and edit care events, attach documents and manage the budget, so that my relative's care is planned and paid for.

- Acceptance criteria: AC-12 to AC-18

## US-04
As a Family member, I want my changes to reach the admin and the carer, so that the people delivering care work from the same plan.

- Acceptance criteria: AC-19 to AC-23

## US-05
As an admin, I want my shifts, events, ticks, top-ups and staff changes to reach the family and the carer, and my lists to agree, so that rostering and records stay consistent.

- Acceptance criteria: AC-24 to AC-31
- Requirements: REQ-23, REQ-24, REQ-25, REQ-26, REQ-32

## US-06
As a carer, I want to see only my clients, change things only while on shift, and have what I record reach the family and admin with costs deducted once, so that care and spending are recorded correctly.

- Acceptance criteria: AC-32 to AC-38
- Requirements: REQ-17, REQ-18, REQ-19, REQ-37

## US-07
As a Family member, I want to move to another organisation without losing history, so that care continues safely.

- Acceptance criteria: AC-39
- Requirements: REQ-04, REQ-N6

## US-08
As a Family member or admin, I want budget warnings and pending costs emailed to me, so that funds are topped up in time.

- Acceptance criteria: AC-40, AC-41
- Requirements: REQ-31, REQ-37
