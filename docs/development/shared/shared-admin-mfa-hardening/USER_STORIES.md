# User Stories — F0-20 Admin TOTP MFA hardening

## US-01
As an admin, I want to set up two-factor sign-in without errors, so that my account is protected from the first sign-in.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-04, AC-07
- Requirements: REQ-01

## US-02
As an admin, I want a wrong code to be cleared and explained, so that I can retry without confusion.

- Acceptance criteria: AC-05, AC-06
- Requirements: REQ-01

## US-03
As the organisation, I want the gate to hold and never expose credentials, so that admin access to client data stays protected.

- Acceptance criteria: AC-08, AC-09
- Requirements: REQ-01
