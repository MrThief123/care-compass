# User Stories — F0-25 Client Documents page

## US-01
As a family member or carer, I want to see all of a client's documents in one place, so that I can find any file quickly.
- Acceptance criteria: AC-01 to AC-04, AC-12, AC-13

## US-02
As a family member or carer, I want to search and sort documents by name, size or date added, so that I can find the one I need.
- Acceptance criteria: AC-05 to AC-07

## US-03
As a family member or carer, I want to download every document at once, so that I can share or keep a full copy.
- Acceptance criteria: AC-08 to AC-11
