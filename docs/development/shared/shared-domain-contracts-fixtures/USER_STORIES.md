# User Stories — UI-00 Domain types, data-access contracts and design fixtures

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a developer, I want one typed contract and realistic sample data, so that I can build screens now and connect real data later without rewriting them.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-04, AC-05, AC-06
- Requirements: REQ-N9, REQ-19
