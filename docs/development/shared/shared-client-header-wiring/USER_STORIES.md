# User Stories — F0-20 Client header wiring and family route guard

## US-01
As a family member, I want every Family page to show my client's real name, age, suburb and organisation, so that I know I am looking at the right person.

- Acceptance criteria: AC-01 to AC-04, AC-08
- Requirements: REQ-02

## US-02
As a family member, I want to be sent away from a client I am not linked to, so that I never see another family's pages.

- Acceptance criteria: AC-05 to AC-07
- Requirements: REQ-05
