# User Stories — F0-29

- **US-01** As a family member, I can tag a care event (for example "Doctors") when I add or edit it, reusing my tags or making a new one.
- **US-02** As a family member or carer, I can filter the Task log by a tag so I see only that kind of care, across the whole history.
- **US-03** As a family member, I can tag documents, and as a family member or carer I can filter the Documents page by tag.
