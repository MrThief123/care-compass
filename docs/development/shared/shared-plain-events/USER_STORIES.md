# User Stories — UI-05 Plain events in the shared kit and contracts (CHG-009)

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a screen owner, I want the domain types and contracts to tell tasks from plain events, with a plain event carrying no status, so that my screen can list both and never show a plain event as Planned, Done or Overdue.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-04, AC-05, AC-06
- Requirements: REQ-35, REQ-17

## US-02
As a screen owner, I want shared calendar, list and form components that draw a plain event in a neutral "Event" look and let the event form switch between task and plain event, so that every dashboard shows them the same way.

- Acceptance criteria: AC-07, AC-08, AC-09, AC-10, AC-11, AC-12, AC-13
- Requirements: REQ-35, REQ-17
