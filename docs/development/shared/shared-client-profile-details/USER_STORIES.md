# User Stories — F0-28

- **US-01** As a family member signing up, I can add my person's date of birth, contact details, address and an emergency contact, or skip them, so the record starts complete.
- **US-02** As a family member, I can view and change those details in Settings at any time.
- **US-03** As a family member, carer or admin, I can see those details on Client Details so I know who to contact and how old the person is.
