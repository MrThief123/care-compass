- `npm install -D supabase` pulled in a critical `tar` vulnerability — reverted, used the global CLI instead (FD-01).
- `import "server-only"` always throws under plain Vitest (no `react-server` resolve condition) — fixed with a vitest alias to its no-op build, not by removing the guard.
- A second `no-restricted-imports` ESLint block silently overwrote the existing UI-00 mocks-restriction rule for overlapping files (flat config quirk) — caught by the full suite, fixed by disjointing the file sets.
- Port 3000 was already bound by an unrelated Docker container on this machine (serving unrelated "Hello from Acquisitions!" content, not this app), so Playwright's `reuseExistingServer` picked it up and the e2e smoke test failed against it. Not a regression from this feature — confirmed by starting the real build on port 3100 and curling it directly (correct `<title>Care Compass</title>`, proxy present, unaffected). Flagging so a human can identify/stop whatever else is on port 3000 before running `npm run test:e2e` locally; not touched by this session.
