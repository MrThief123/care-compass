# User Stories — INT-09 Overdue and upcoming care alert emails

## US-01
As a family member or organisation admin, I want an email when care for the person I look after is overdue, so that I can follow it up without checking the app.

- Acceptance criteria: AC-01 to AC-04, AC-06, AC-07
- Requirements: REQ-33

## US-02
As the project owner, I want only the job's own scheduler to be able to trigger it, so that nobody can make the system send emails.

- Acceptance criteria: AC-05
- Requirements: REQ-33

## US-03
As a recipient, I want the email to say which task, for whom and when, so that I know what to do without opening the app first.

- Acceptance criteria: AC-08
- Requirements: REQ-33
