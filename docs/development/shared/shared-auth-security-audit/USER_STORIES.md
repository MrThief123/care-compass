# User Stories — F0-21 Auth security audit

## US-01
As the organisation, I want admin data to require two-factor sign-in at the database, so that skipping the screens does not skip the second factor.

- Acceptance criteria: AC-01
- Requirements: REQ-01

## US-02
As a family or organisation, I want no other tenant to be able to read or change our records by swapping IDs, so that client data stays private.

- Acceptance criteria: AC-03
- Requirements: REQ-01

## US-03
As the organisation, I want sessions, sign-in attempts and forms to be hardened, so that accounts are hard to steal or brute-force.

- Acceptance criteria: AC-02, AC-04, AC-05, AC-06
- Requirements: REQ-01
