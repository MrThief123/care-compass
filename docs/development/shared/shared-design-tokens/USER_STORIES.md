# User Stories — F0-05 Design tokens, typography and base styles

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a user with low vision, I want text that meets contrast standards, so that I can read the app comfortably.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-04
- Requirements: REQ-N2, REQ-N3
