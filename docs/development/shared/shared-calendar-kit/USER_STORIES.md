# User Stories — UI-01 Calendar kit: week/day/month grids, event blocks, date picker

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a family member or carer, I want calendars that behave like normal calendars, so that I can read schedules without learning anything new.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-04, AC-05, AC-06
- Requirements: REQ-16, REQ-25, REQ-23
