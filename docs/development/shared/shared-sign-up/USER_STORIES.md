# User Stories — F0-17 Self-serve sign-up for Family and Organisation accounts

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a family member, I want to create my own account and add the person I care for, so that I can start their care schedule without waiting for anyone.

- Acceptance criteria: AC-01, AC-03, AC-04, AC-08
- Requirements: REQ-01, REQ-36

## US-02
As an organisation manager, I want to register my organisation and my admin account, so that my team can start managing clients who choose us.

- Acceptance criteria: AC-02, AC-03, AC-04, AC-08
- Requirements: REQ-01, REQ-36

## US-03
As a family member, I want public sign-up to be unable to grant carer or organisation access, so that only people my provider invites can see my family member's records.

- Acceptance criteria: AC-05, AC-06, AC-07
- Requirements: REQ-03, REQ-36
