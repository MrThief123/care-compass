# User Stories — F0-23 Link uploaded documents to a new event

## US-01
As a family member adding an event, I want files I attach to be on the event when I save it, so that I do not have to save first and open it again.

- Acceptance criteria: AC-06, AC-07, AC-08
- Requirements: REQ-22

## US-02
As the owner of a client's records, I want a document to be linked to an event only by someone allowed to, only once, and only to that client's own event, so that files never end up on another client's event.

- Acceptance criteria: AC-01 to AC-05
- Requirements: REQ-22
