# User Stories — F0-26 Custom sections on Client Details

## US-01
As a family member, carer on shift or organisation admin, I want to add a section with my own title, so that I can record information that doesn't fit Description, Habits or Medical history.
- Acceptance criteria: AC-01, AC-02, AC-03, AC-08

## US-02
As a family member, carer on shift or organisation admin, I want to rename a custom section and edit its text, so that it stays accurate.
- Acceptance criteria: AC-04, AC-05, AC-14

## US-03
As a family member, carer on shift or organisation admin, I want to remove a custom section after confirming, so that out-of-date headings don't clutter Client Details.
- Acceptance criteria: AC-06, AC-11

## US-04
As anyone caring for the client, I want custom sections to show on every dashboard with the right controls for my role, so that we all read the same information.
- Acceptance criteria: AC-07, AC-09, AC-10, AC-12, AC-13, AC-15, AC-16
