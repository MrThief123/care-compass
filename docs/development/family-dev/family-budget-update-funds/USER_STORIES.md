# User Stories — FAM-11 Family — Update funds (Edit budget)

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a family member (or the organisation's admin acting as Family), I want to save changes on Edit budget, so that the stored budget and History are correct.

- Acceptance criteria: AC-01, AC-02, AC-04, AC-05, AC-06, AC-07, AC-08
- Requirements: REQ-29, REQ-38

## US-02
As the person who owns the budget, I want only the family and the client's organisation admins to change it, so that nobody else can alter a vulnerable person's money.

- Acceptance criteria: AC-03
- Requirements: REQ-29, REQ-38
