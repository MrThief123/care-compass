# User Stories — FAM-UI-08 Family event cost fields (UI)

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a family member, I want to give an event a cost and choose which funding bucket pays for it, so that the budget comes down by the right amount when the care is done.

- Acceptance criteria: AC-01, AC-02, AC-05
- Requirements: REQ-37

## US-02
As a family member, I want buckets with no money left to be crossed out and low ones to warn me, so that I don't plan care against money that isn't there.

- Acceptance criteria: AC-03, AC-04
- Requirements: REQ-37, REQ-N1

## US-03
As a family member, I want to see and change an event's cost when I edit it, so that future care is charged correctly.

- Acceptance criteria: AC-06
- Requirements: REQ-37
