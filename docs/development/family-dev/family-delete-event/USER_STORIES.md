# User Stories — FAM-18 Family — Delete event and recurrence end date

## US-01
As a family member or on-shift carer, I want to delete an event, so that cancelled care leaves the schedule.
- Acceptance criteria: AC-01, AC-02, AC-08, AC-09, AC-10, AC-11, AC-16, AC-17

## US-02
As a family member or on-shift carer, I want to delete just one occurrence or this and all future ones of a repeating event, so that I can cancel one visit or stop a series without losing past care.
- Acceptance criteria: AC-03, AC-04, AC-05, AC-06, AC-07

## US-03
As a family member or on-shift carer, I want to give a repeating event an end date, so that a course of care stops by itself.
- Acceptance criteria: AC-12, AC-13, AC-14, AC-15
