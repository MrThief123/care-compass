# User Stories — FAM-UI-05 Family Budget screen (UI)

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a family user, I want the Family · Budget screen to look and behave as designed, so that the team and client can review it before data is connected.

- Acceptance criteria: AC-01, AC-02, AC-03
- Requirements: REQ-02, REQ-N1, REQ-N2, REQ-N3

## US-02
As a family member or admin, I want to add or remove money from a bucket with one simple form, so that the budget matches the funds we actually have. (CHG-020)

- Acceptance criteria: AC-04, AC-05, AC-06
- Requirements: REQ-29

## US-03
As a family member or admin, I want to see costs waiting on a bucket that ran out, so that I know to add funds. (CHG-020)

- Acceptance criteria: AC-07, AC-08
- Requirements: REQ-37
