# User Stories — FAM-16 Family — Event form and calendar polish

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a family member or carer, I want a late-completed task to say how late it was done, so that I can see missed timing without comparing clocks.
- Acceptance criteria: AC-01, AC-02, AC-03, AC-04
- Requirements: REQ-17, REQ-19

## US-02
As any user picking a date, I want today marked and the calendar open on the month of my date, so that I never hunt for the right month.
- Acceptance criteria: AC-05, AC-06, AC-07
- Requirements: REQ-18

## US-03
As a family member or on-shift carer, I want to enter an event's start and end time, so that it works like a shift.
- Acceptance criteria: AC-08, AC-09, AC-10, AC-11
- Requirements: REQ-18, PD-047
