# User Stories — CAR-07 Carer — Add and edit events for a patient

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a carer on shift, I want to add a care event for my patient, so that a need I notice gets scheduled and the family sees it.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-04, AC-06, AC-07
- Requirements: REQ-18

## US-02
As a carer on shift, I want to edit an event for my patient, so that I can correct a time or add a document without asking the family.

- Acceptance criteria: AC-05, AC-06, AC-07
- Requirements: REQ-18

## US-03
As a family member, I want the Family screens to behave exactly as before, so that carer access does not change what I see or can do.

- Acceptance criteria: AC-08
- Requirements: REQ-18
