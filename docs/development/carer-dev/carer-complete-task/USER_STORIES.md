# User Stories — CAR-06 Carer — Mark tasks done

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a carer, I want to tick off care as I do it, so that the family and my manager can see it's done.

- Acceptance criteria: AC-01 to AC-05
- Requirements: REQ-18, REQ-19, REQ-05

## US-02
As a carer, I want to see my patient's Home, Calendar and Care log the way their family does, so that I know what has been done and what is due.

- Acceptance criteria: AC-06, AC-07, AC-08
- Requirements: REQ-05, REQ-18
