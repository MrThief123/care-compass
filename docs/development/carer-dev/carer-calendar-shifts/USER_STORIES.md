# User Stories — CAR-05 Carer — Calendar (shifts) and selected-shift tasks

Format: As a [user], I want [capability], so that [outcome].

## US-01
As a carer, I want to see my real shifts in Day, Week and Month, so that I know when and who I'm working with.

- Acceptance criteria: AC-01, AC-02, AC-03, AC-04, AC-08, AC-09, AC-10
- Requirements: REQ-25

## US-02
As a carer, I want each shift to show the client's full name, even for a shift that has ended, so that I can tell two clients with the same first name apart and check last week.

- Acceptance criteria: AC-05, AC-06, AC-07
- Requirements: REQ-25
